# Yoonsite

이 리포지토리는 윤재 구 님의 개인 웹사이트 프로젝트입니다. 여기에는 네온 스네이크 게임과 피하기 게임이 포함되어 있습니다.

## 프로젝트 소개
- **네온 스네이크 게임**: 클래식 스네이크 게임의 네온 버전
- **피하기 게임**: 장애물을 피하는 간단한 게임

## 파일 구조
| 파일명 | 설명 |
|--------|------|
| `index.html` | 메인 HTML 파일
| `main.js` | 메인 자바스크립트 파일 (게임 로직 포함)
| `style.css` | 스타일 시트 파일
| `neon_snake_v2_1772335208525.png` | 네온 스네이크 게임 이미지
| `poo_dodge_v2_1772335193193.png` | 피하기 게임 이미지
| `CNAME` | 커스텀 도메인 설정 파일
| `google86675918c73236a3.html` | 구글 검색 콘솔 인증 파일

## 설치 및 실행
1. 이 리포지토리를 클론합니다.
   ```bash
   git clone https://github.com/yoonjaekoo/yoonsite.git
   ```
2. `index.html` 파일을 브라우저에서 엽니다.

## 라이선스
이 프로젝트는 개인 용도로 제작되었습니다. 상업적 사용은 허용되지 않습니다.
